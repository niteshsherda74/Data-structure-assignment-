# College Assignments

Store each college assignment in its own clearly named folder.

## Suggested structure

```text
Assignments/
├── Assignment-01/
│   ├── README.md
│   ├── source-files...
│   └── assets/             # Optional: screenshots or supporting files
├── Assignment-02/
└── ...
```

For each assignment, include the assignment title, objective, concepts covered, files, and how to compile/run it where relevant.

*Assignment folders will be added as the coursework is provided.*
