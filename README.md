## Projects

### [Encrypted Password Manager](./Password-Manager/)

A command-line C mini project demonstrating data structures such as a hash table, binary search tree, stack, and linked lists, alongside an educational cryptographic storage layer.

See the [project README](./Password-Manager/README.md) for features, architecture, build instructions, testing, limitations, and security notes.

> **Security note:** This is an educational academic project. Its custom cryptographic implementation should not be relied on to protect real passwords or sensitive data.
